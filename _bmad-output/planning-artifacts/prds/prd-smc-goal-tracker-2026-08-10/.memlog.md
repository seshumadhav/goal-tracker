- (decision) Product: single-user personal goal tracker with 3 goal types: target (e.g. weight, has starting value+target+deadline+direction), aggregate (e.g. meditation minutes, cumulative toward target by deadline), streak (e.g. no-non-veg, consecutive days).
- (decision) Home screen has 2 sections: log today's progress across all goals, and overall progress per goal.
- (decision) Separate Goals List page: shows all goals as links, allows creating new goal.
- (decision) Backend: user's personal Google Sheet (their own Gmail account) as data store.
- (decision) UI: minimal, modern, low text clutter, no traditional thick colors; mobile-browser-first (primary usage device is mobile), but should work multi-device.
- (decision) Stakes: hobby/personal use, working mode: Fast path with assumption tags.
- (decision) Streak rule: a day with no log entry breaks the streak (must log daily to maintain).
- (decision) Target goals: capture starting value + target value + direction at creation; progress shown as % toward target.
- (decision) v1 scope: append-only logging, no editing/deleting past entries.
- (decision) Access model: Sign in with Google (OAuth) each session rather than a fixed no-login sheet.
- (event) Research digest gathered on comparable apps (Strides, Way of Life, Streaks, Habitica) and Google Sheets API pitfalls (quota, offline, auth) to inform NFRs.
- (decision) Deployment/dev standards should mirror two existing sibling projects on this machine: image-hospital and the-chocolate-room.
- (event) Inspected image-hospital and the-chocolate-room: both are Node.js backends (Express/TS), deployed to a single shared AWS EC2 instance via PM2 process manager + Nginx reverse proxy; DuckDNS for free dynamic DNS + Let's Encrypt (DNS-01/certbot) for HTTPS; GitHub Actions CI (tests+typecheck) gates a separate Deploy workflow that SSHes in (appleboy/ssh-action) and runs deploy.sh (git pull/reset, npm install/build, pm2 restart, sync nginx conf, nginx -t, reload) on push to main; docs convention is PRD.md + ARCHITECTURE.md/DECISIONS.md + CLAUDE.md for agent instructions; tests run before and after any change per CLAUDE.md.
- (decision) Goal Tracker will follow the same pattern: Node.js/Express backend, deployed on the same (or sibling) EC2 instance under PM2 + Nginx + DuckDNS subdomain + Let's Encrypt, with GitHub Actions CI+CD mirroring the two sibling repos.
